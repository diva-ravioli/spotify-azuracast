Install spotify-azuracast

This puts your own copy on your free Cloudflare account. You don't need a GitHub account or anything installed.

1. Make a Cloudflare API token

On Cloudflare's API tokens page, choose Create Token. Name it so you'll know later what it is for, such as spotify-azuracast: deleting it would stop your copy's updates. Then choose Start from scratch › Start with an Account policy. Search for Workers Scripts and tick Edit: that is the only permission it needs. Leave it on No expiration, so your copy can keep updating itself, then choose Continue to summary and Create Token, and copy the token it shows you.

2. Find your Account ID

It's in the address of your Cloudflare dashboard: dash.cloudflare.com/your-account-id/…

3. Install

The Worker's name becomes part of your copy's address, which Spotify sees when you connect it, so this one is made up and says nothing about what it is. Keep it, or choose your own without spotify or azuracast in it.

    Installed

    Open it straight away:

    The first Spotify account to complete setup becomes its owner. The page takes you through the rest.

    What happens to your token

    It's kept as an encrypted secret in your own Worker, and used only to install new releases once a day. It passes through a small relay on its way to Cloudflare, because a web page can't call Cloudflare's API directly. The relay keeps and logs nothing, and passes on only what this page asks. The token can change any Worker on your account. To stop updates, delete it on Cloudflare's API tokens page.
